# แผนพัฒนาแอป "ทำคลิปสั้นด้วยโค้ด" สู่ App Store / Google Play

ต่อยอดจาก `video-engine/` ที่ใช้งานได้แล้ว: วาดด้วยโค้ด, พากย์ไทย, QA ตัดขอบ, 9:16/16:9/1:1

## 1. ภาพรวมระบบ

```
[แอปมือถือ Expo]  --พิมพ์หัวข้อ/เลือกสไตล์-->  [API Server]
        ^                                         |
        |  push แจ้งเตือน + ลิงก์วิดีโอ              v
        |                                   [Job Queue]
        |                                         |
        |        +-------------+------------------+------------------+
        |        v             v                  v                  v
        |   1.เขียนบท      2.เสียงพากย์         3.เรนเดอร์           4.QA
        |   Claude API    ElevenLabs TTS      Chromium+ffmpeg     ตัดขอบ/จอดำ/
        |   + web search  + STT ตรวจกลับ       (engine เดิม)        เสียงตรงบท
        |        |             |                  |                  |
        +---- [Storage (S3/R2)] <-----------------+------------------+
```

**ทำไมเรนเดอร์ฝั่งเซิร์ฟเวอร์:** เอนจินใช้ Chromium + ffmpeg ซึ่งรันบนมือถือไม่ได้ และวิดีโอ 27 วินาทีที่ 720p ใช้เวลาเรนเดอร์ราว 20-40 วินาทีบน CPU เดียว ในแอปจะมีพรีวิวแบบเรียลไทม์ (วาด canvas เดียวกันใน WebView/Skia) แต่ไฟล์สุดท้ายเรนเดอร์บนเซิร์ฟเวอร์

## 2. เทคโนโลยีที่เลือก

| ส่วน | เลือก | เหตุผล |
|---|---|---|
| แอปมือถือ | Expo (React Native) + Expo Router | โค้ดเดียว iOS+Android, ส่งสโตร์ด้วย EAS Build/Submit |
| พรีวิวในแอป | `stage.js` เดิมใน WebView (เฟส 1) → react-native-skia (เฟส 2) | ใช้โค้ดวาดชุดเดียวกับเซิร์ฟเวอร์ ภาพตรงกัน 100% |
| API | Node.js (Fastify) + TypeScript | ใช้ภาษาเดียวกับเอนจิน |
| คิวงาน | BullMQ + Redis | retry, progress, จำกัดงานพร้อมกัน |
| Worker เรนเดอร์ | Docker (Playwright image + ffmpeg + ฟอนต์ไทย) บน Cloud Run / Fly.io | สเกลตามคิว |
| ฐานข้อมูล + Auth | Supabase (Postgres + Auth) | มี Sign in with Apple/Google ในตัว |
| ไฟล์วิดีโอ | Cloudflare R2 หรือ S3 + CDN | ค่าส่งออกถูก |
| เขียนบท | Claude API (Opus 5.5 สำหรับบท, Haiku 5.5 สำหรับงานย่อย) + web search tool | บทพร้อมแหล่งอ้างอิงจริง, ส่งออกเป็น JSON ตาม schema |
| เสียง | ElevenLabs (แพ็กเกจเสียเงิน: ใช้เสียงไทยในไลบรารี + speech_to_text) | ตรวจเสียงกลับได้ |
| ชำระเงิน | RevenueCat + In-App Purchase | สโตร์บังคับใช้ IAP สำหรับสินค้าดิจิทัล |

## 3. แผนงานตามเฟส

### เฟส 0 - ทำเอนจินให้แข็งแรง (1-2 สัปดาห์)
- [ ] JSON Schema ของ story (zod) + validator: AI สร้างบทผิดรูปแบบต้องถูกปฏิเสธก่อนเรนเดอร์
- [ ] ระบบตัวละครแบบ "rig": ประกาศชิ้นส่วน+ท่า แทนการเขียนฟังก์ชันวาดเอง → เพิ่มตัวละครได้เร็ว
- [ ] คลังตัวละคร/ฉาก/สไตล์ เริ่ม 10 สไตล์ 10 ตัวละคร (เป้าหมายระยะยาว 100+)
- [ ] QA เพิ่ม: จอดำ/ภาพนิ่งเกินไป, ซับไตเติลล้นจอ, เสียงพากย์ยาวเกินช็อต
- [ ] เทสต์อัตโนมัติ: golden-frame (เทียบภาพเฟรมกับภาพอ้างอิง) ทุกสไตล์ × ทุกสัดส่วนจอ
- [ ] เรนเดอร์เร็วขึ้น: แบ่งช่วงเฟรมเรนเดอร์ขนาน แล้วต่อด้วย ffmpeg concat

### เฟส 1 - Backend + คิวเรนเดอร์ (2 สัปดาห์)
- [ ] API: `POST /projects`, `POST /projects/:id/render`, `GET /jobs/:id` (progress), webhook เสร็จงาน
- [ ] Worker Docker image + autoscale
- [ ] เก็บวิดีโอใน R2, ลิงก์แบบ signed URL
- [ ] ระบบเครดิต: หักเครดิตตามความยาวคลิป + ตัวอักษรพากย์

### เฟส 2 - AI เขียนบท (2 สัปดาห์)
- [ ] หัวข้อเดียว → Claude ค้นข้อมูล (web search) → โครงเรื่อง → story JSON + แหล่งอ้างอิง
- [ ] ให้ผู้ใช้อนุมัติบทก่อนเสียเครดิตเสียง/เรนเดอร์
- [ ] กรองเนื้อหาไม่เหมาะสม (สโตร์บังคับสำหรับแอปที่สร้างเนื้อหาด้วย AI)
- [ ] (ภายหลัง) "เลียนสไตล์คลิปที่ชอบ": วิเคราะห์เฟรมตัวอย่าง → เลือกพาเลต/จังหวะตัดต่อ + คะแนนความเหมือน

### เฟส 3 - แอปมือถือ MVP (3 สัปดาห์)
หน้าจอ:
1. Onboarding + เข้าสู่ระบบ (Apple / Google / อีเมล)
2. หน้าหลัก: "พิมพ์หัวข้อ" + แกลเลอรีเทมเพลต
3. เลือกสไตล์ / สัดส่วนจอ / เสียงพากย์
4. ตรวจและแก้บท (แก้ข้อความต่อช็อตได้)
5. พรีวิวแบบเรียลไทม์ (WebView)
6. สถานะเรนเดอร์ + push notification
7. คลังวิดีโอของฉัน: ดาวน์โหลด / แชร์ไป TikTok, Reels, Shorts
8. ร้านค้าเครดิต/สมาชิก (paywall)
9. ตั้งค่า: **ลบบัญชี** (Apple บังคับ), นโยบายความเป็นส่วนตัว, รายงานเนื้อหา

### เฟส 4 - รายได้ (1 สัปดาห์)
- [ ] RevenueCat: สมาชิกรายเดือน + ซื้อเครดิตเพิ่ม
- [ ] ทดลองฟรี: 2-3 คลิปลายน้ำ

### เฟส 5 - ส่งขึ้นสโตร์ (1-2 สัปดาห์)
- [ ] บัญชี Apple Developer (รายปี) + Google Play Console (ครั้งเดียว)
- [ ] EAS Build + EAS Submit, TestFlight / Internal testing
- [ ] Privacy label / Data safety form, age rating, ภาพหน้าจอสโตร์ (ปลั๊กอิน appstore-screenshots)
- [ ] ตรวจก่อนส่ง (ปลั๊กอิน Mobile Release Check)
- [ ] เตรียมตอบรีวิว Apple: ระบุว่าใช้ AI สร้างเนื้อหา, มีการกรองและปุ่มรายงาน

## 4. ความเสี่ยงและสิ่งที่ต้องตัดสินใจ
- **ต้นทุนต่อคลิป** = โทเคน Claude + ตัวอักษร ElevenLabs + เวลา CPU เรนเดอร์ → วัดจริงในเฟส 1 ก่อนตั้งราคา
- **ลิขสิทธิ์**: สไตล์/ตัวละครต้องออกแบบเอง ไม่ลอกตัวละครที่มีเจ้าของ, ฟีเจอร์ "เลียนสไตล์" ต้องเลียนแค่องค์ประกอบทั่วไป (สี จังหวะ) ไม่ใช่ตัวละคร
- **สิทธิ์เสียงพากย์**: ใช้เสียงเชิงพาณิชย์ได้ตามแพ็กเกจ ElevenLabs ที่สมัคร
- **เวลารอเรนเดอร์**: ต้องมี progress + แจ้งเตือน ไม่ให้ผู้ใช้จ้องหน้าจอรอ
